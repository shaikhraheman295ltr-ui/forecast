# Forecast — Weather Intelligence

https://forecast-steel-theta.vercel.app

A monochrome weather dashboard with live global temperature map.

### Features
- Current weather (temp, feels-like, wind, humidity, UV, pressure, visibility, rain)
- Sunrise & sunset times
- Live world temperature map (22 cities, color-coded from blue to red)
- 24-hour forecast chart (temp, feels-like, rain)
- 3-day forecast with condition icons and rain probability
- Dark/light theme toggle
- Search by city or GPS geolocation
- Skeleton loading, toast notifications, responsive design
